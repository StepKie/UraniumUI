# Guides

Guides are practical, problem-focused articles for .NET MAUI developers. They are different from reference documentation: a guide should start from a real developer problem and show how UraniumUI can solve it.

This section is reserved for SEO-focused tutorials such as:

- How to validate forms in .NET MAUI
- How to build dynamic forms in .NET MAUI
- How to create reusable dialogs in .NET MAUI
- How to theme a .NET MAUI app without vendor lock-in

Use the reference documentation when you already know which UraniumUI feature you need:

- [Forms & Validation](../infrastructure/AutoFormView.md)
- [Material Theme](../themes/material/Index.md)
- [Dialogs](../dialogs/Index.md)
- [Styling, Theming & Effects](../theming/ColorSystem.md)
